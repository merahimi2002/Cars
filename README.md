# آذرخش

سایت استاتیک با نمایش سه‌بعدی پنج خودرو: Lamborghini Huracán Spyder، Ferrari 458 Italia، BMW M4 Competition، Porsche 911 Carrera 4S و Nissan Skyline GT-R R34.

## اجرا و GitHub Pages

برای اجرا، `index.html` را مستقیم در مرورگر باز کنید؛ به نصب Node.js یا اجرای سرور نیازی نیست. برای GitHub Pages، فایل HTML و پوشه‌های CSS، js، Image و assets را همراه فایل‌های مستقل در ریشهٔ مخزن قرار دهید. فایل `.nojekyll` ساختار استاتیک را حفظ می‌کند.

## پیش‌نمایش با سرور محلی (اختیاری)

فایل **Start.cmd** را دوبار کلیک کنید. Node.js باید نصب باشد. سرور محلی در پس‌زمینه اجرا می‌شود و مرورگر آدرس http://localhost:4173/ را باز می‌کند. اجرای دوبارهٔ Start.cmd از همان سرور استفاده می‌کند.

برای اجرای دستی:

```sh
node scripts/serve.cjs
```

فایل `index.html` را می‌توانید مستقیم باز کنید. در مسیر `file://`، نسخهٔ مستقل از اسکریپت‌های معمولی و دادهٔ مدل‌های محلی استفاده می‌کند و به سرور نیاز ندارد. در GitHub Pages، همان `index.html` نسخهٔ ماژولی و فایل‌های GLB را از HTTPS بارگذاری می‌کند. همهٔ مسیرها نسبی‌اند تا در آدرس `/Cars/` هم کار کنند.

خودروهای دیگر با اولین انتخاب دانلود می‌شوند و تا زمانی که صفحه باز است در حافظه نگه داشته می‌شوند. فایل‌های GLB و کتابخانه‌ها همگی داخل پروژه قرار دارند.

منابع و مجوز فایل‌ها در [assets/ASSET-CREDITS.md](assets/ASSET-CREDITS.md) ثبت شده‌اند.

## ساخت دوبارهٔ نسخهٔ مستقل

فایل‌های مستقل از قبل ساخته شده‌اند و باید همراه پروژه در گیت قرار بگیرند. بعد از تغییر کد شوروم یا مدل‌ها، این دو فرمان را اجرا کنید:

```sh
npm install --prefix .build-tools --no-audit --no-fund esbuild@0.25.12
node scripts/build-standalone.cjs
```

فایل‌های `*.local.js` نسخهٔ Base64 همان مدل‌ها هستند؛ نگهداری آن‌ها کنار GLBها برای پشتیبانی هم‌زمان از فایل محلی و GitHub Pages است. هیچ فایل تکی به محدودیت ۱۰۰ مگابایت گیت‌هاب نمی‌رسد.

## ساختار پروژه

سکشن `discover` به خودروی انتخاب‌شده و رنگ آن در هیرو متصل است. دوربین جزئیات با اسکرول حرکت می‌کند و در موبایل، تصویر بالای کارت‌های روایت ثابت می‌ماند. مدل دوباره دریافت نمی‌شود؛ رندر جزئیات هنگام نزدیک‌شدن به سکشن آماده می‌شود و خارج از دید متوقف می‌شود. تنظیم «کاهش حرکت» دستگاه هم رعایت می‌شود.

اطلاعات و لینک منابع سازنده در `js/drive-data.js`، حرکت دوربین در `js/drive-story.js` و استایل بخش در `Css/drive-story.css` قرار دارند.

- `index.html`: صفحهٔ اصلی و کنترل‌های شوروم
- `Css/`: استایل سایت، شوروم و کتابخانه‌های مورد استفاده
- `js/`: تنظیمات ظاهر، نمایش خودرو، چرخ‌ها و منظرهٔ سه‌بعدی
- `js/vendor/`: کتابخانه‌های محلی Three.js و Draco به همراه مجوزها
- `assets/models/`: مدل‌های GLB و نسخه‌های مستقل همان مدل‌ها
- `Image/` و `fonts/`: تصاویر و فونت‌های مورد استفاده
- `scripts/`: ابزارهای اختیاری پیش‌نمایش و ساخت نسخهٔ مستقل

برای انتشار، کل فایل‌های پروژه به‌جز موارد داخل `.gitignore` را پوش کنید. در تنظیمات GitHub Pages، شاخهٔ مورد نظر و پوشهٔ `/ (root)` را انتخاب کنید. فایل‌های `*.local.js`، `showroom.standalone.js` و `local-decoder.js` خروجی ضروری‌اند و نباید حذف شوند. وابستگی‌های ساخت فقط با فرمان نصب بالا ایجاد می‌شوند و وارد گیت نمی‌شوند.
